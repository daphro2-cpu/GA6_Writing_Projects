# GA6 Writing Projects

Interactive teaching website for Writing Project 3: processes that use wheels.

Open `index.html` in a browser. The encyclopedia is `wheel-pack.pdf`. All photos, illustrations, textbook pages and scripts are included for offline use.

Classroom notes and drawings save in this browser on this device. Use Save backup to download a JSON backup, and restore it when moving devices.

This private repository preserves the teaching materials; GitHub Pages has not been enabled.
